SGS HTML Loading Diagnostic 2

Controlled tests for determining which browser capability or policy prevents a game document from loading.
1. Same-document iframe
2. External HTTPS iframe
3. Blob HTML document
4. Data HTML document
5. External JavaScript
6. Dynamic script execution
What the results mean
  • If same-document works but external HTTPS iframe fails, investigate URL/domain filtering or frame navigation policy.
  • If external iframe works but blob/data fails, investigate restrictions on special URL schemes.
  • If all iframe tests work but external JavaScript fails, investigate script/content filtering.
  • If all of these pass, the game's own JavaScript/runtime is the next thing to inspect.
