Safe diagnostic simulation. This page does not retrieve blocked games, proxy traffic, or bypass school controls. It demonstrates the kinds of loading paths IT should account for using only resources generated by this page.

Controlled tests

What IT should look for

  • Whether the managed profile permits each browser loading mechanism.
  • Whether controls inspect the final resource or only the original URL.
  • Whether iframe navigation is treated differently from top-level navigation.
  • Whether script execution is allowed after a resource is created locally.
  • Whether policy enforcement is consistent across personal and managed profiles.
